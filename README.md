# Student Index Recovery (Flash Hack V3.0 - PS12)

Merges valid BST fragments (1–3 nodes each) into a single valid BST using every fragment once, or reports `IMPOSSIBLE` with the reason.

## Build & Run
```bash
gcc -Wall -Wextra -O2 student_index_BST.c -o demo
./demo
```

## Example Input
```text
3
2 1 -
3 2 5
5 4 -
```
